# 체스 (PWA)

컴퓨터와 두는 체스 웹앱입니다. 폰/태블릿에 설치하면 앱처럼 실행되고, 오프라인에서도 플레이할 수 있어요.
빌드 도구 없이 `index.html` 한 파일로 동작합니다.

## 기능
- 컴퓨터 대전 4단계(입문·쉬움·보통·어려움), 둘이서 두기, 백/흑 선택
- 모든 규칙: 캐슬링, 앙파상, 프로모션 선택, 체크메이트·스테일메이트, 3회 반복·기물 부족·50수 무승부
- **배우기 모드**: 말 이동법 안내, 위험한 수 경고, 수 평가 한마디
- 힌트, 무르기, 기권, 보드 뒤집기
- 시계(무제한·1분·3분+2초·5분·10분)
- 기보 표와 되돌려보기(⏮ ◀ ▶ ⏭, 방향키)
- 클릭 이동 + 드래그 앤 드롭
- 수 평가 배지(`!!` `!` `?!` `?` `??`), 말 이동 슬라이드·잔상, 체크메이트 연출, 효과음
- 메뉴 숨기기, 라이트/다크 모드, 폴드 같은 넓은 화면 레이아웃

## 로컬에서 실행
서비스 워커는 `file://`에서는 동작하지 않으니 간단한 서버로 여세요.

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## GitHub Pages로 배포
1. 이 폴더를 GitHub 레포에 푸시
2. 레포 **Settings → Pages → Build and deployment**
3. Source: **Deploy from a branch**, Branch: **main**, Folder: **/ (root)** → Save
4. 1~2분 뒤 `https://<사용자명>.github.io/<레포명>/` 에서 열립니다 (HTTPS라서 PWA 설치 가능)

## 폰에 설치
- Android Chrome: 주소창 메뉴(⋮) → **홈 화면에 추가 / 앱 설치**
- iPhone Safari: 공유 버튼 → **홈 화면에 추가**
- 데스크톱 Chrome·Edge: 주소창 오른쪽의 설치 아이콘

## 수정 후 업데이트하기
`sw.js` 맨 위의 `const V = "chess-v1";` 숫자를 올린 뒤 푸시하세요(`chess-v2` …).
그래야 이미 설치된 앱이 새 파일을 받아요. 새 버전은 앱을 연 뒤 한 번 더 열 때 적용됩니다.

## 구성
```
index.html            게임 전체(HTML + CSS + JS)
manifest.webmanifest  PWA 설정
sw.js                 서비스 워커(오프라인 캐시)
icons/                앱 아이콘(192, 512, maskable, apple-touch)
```
